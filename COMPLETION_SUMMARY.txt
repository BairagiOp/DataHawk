RESEARCH QUESTIONS IMPLEMENTED (7/7)
================================================================================

RQ1: Semantic vs Frequency-Based Topic Clustering
     ✅ Implementation: HDBSCAN + embeddings
     ✅ Baseline: TF-IDF + K-Means
     ✅ Alternative: LDA
     ✅ Metrics: Silhouette, coherence, purity

RQ2: Does Preprocessing Improve Reliability?
     ✅ Implementation: Deduplication + spam filtering + language detection
     ✅ Baseline: Raw data
     ✅ Metrics: Precision, recall, false positive rate

RQ3: Composite > Simple Trend Scoring?
     ✅ Implementation: α·V + β·G + γ·E + δ·N (composite formula)
     ✅ Baseline: Frequency-based counting
     ✅ Alternative: Simple growth rate
     ✅ Metrics: Precision@K, recall@K, NDCG

RQ4: Early Emerging Trend Detection?
     ✅ Implementation: 5-category classification (EMERGING/VIRAL/RISING/STABLE/DECLINING)
     ✅ Baseline: Frequency thresholding
     ✅ Metrics: Detection time, false positive rate, early detection advantage

RQ5: LLM Improves Interpretability?
     ✅ Implementation: LLM-based topic labeling with explanations
     ✅ Baseline: Top-N keywords
     ✅ Metrics: Human rating, semantic consistency

RQ6: Accuracy vs Cost Trade-Offs?
     ✅ Implementation: Track latency, memory, API cost
     ✅ Metrics: Seconds/100 posts, GB peak RAM, $/post

RQ7: Trend Forecasting Accuracy?
     ✅ Implementation: XGBoost + Random Forest ensemble
     ✅ Baseline 1: Naive forecast
     ✅ Baseline 2: Moving average
     ✅ Baseline 3: Linear regression
     ✅ Metrics: MAE, RMSE, MAPE, directional accuracy
